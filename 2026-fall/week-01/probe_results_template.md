## Section 7 — What you made of it

**1. Which question did the model handle best, and which worst? Why do you think
that is?**

`Two or three sentences. Consider what each question had to work from.`


**2. Look back at every answer you marked No or Sort of. How sure did the model
sound on those?**

`This is the one worth slowing down on. If a wrong answer was delivered flatly,
with no hedge, say so and quote it. If the model hedged exactly where it was
wrong, say that too, because that is the tool working the way you would want and
it matters which one you are dealing with.`


**3. Questions 3, 4, and 5 were all things you never told it, so it knew the same
amount about all three, which is nothing. Did it treat them the same way?**

`If it answered some and declined others, what separates them? It is not that it
knew more about one. Think about how easily each answer could be checked by the
person asking.`
